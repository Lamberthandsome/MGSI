# 全局块范围索引的构造与查询规则

`chunk_tree.py` 和 `index.py` 对应当前正文 Global Index 小节的 Eq.4–6 和 Algorithm 1。

每个非空子树重新计算其代表点的逐维质心，选择平方欧氏距离最小的块为枢轴；完全并列时按唯一块编号的字符串顺序选择。根深度为0，代码维度编号从0开始，分割维度为 `depth % k`。剔除枢轴后，小于其分割坐标的点进入左子树，其余点进入右子树。空子树和单块终止。初始按ID排序，稳定分支保留顺序，保证输入顺序不影响结果。构造与查询都使用显式栈；不保证平衡，重复坐标可形成长度为N的链。

每个节点的上下界覆盖该子树中所有块的**完整逻辑边界**。查询只在某一维满足 `subtree_max < query_min` 或 `subtree_min > query_max` 时跳过整个子树；否则检查枢轴块自己的完整边界，并继续检查两个子树。采用闭区间，边界接触计为相交。块候选选择之后仍须执行实际记录的空间、时间和变量谓词。

`ChunkTree` 接收唯一字符串ID和k维有限坐标，边界须满足low<=high，代表点须在块内。边界不能跨经度周期；跨日期变更线的查询须先分解成普通框。所有维度在元数据和查询中须使用相同顺序和编码。适配器 `MGSIIndex()` 默认按 `(lon, lat)` 的下角坐标建树；`MGSIIndex(axes=('lon', 'lat', 'time'))` 可以接收已经统一编码的数值时间边界。没有时间界限的现有入口继续使用二维空间筛选。完整文件消融的代表点保留文件中心，仍采用相同构树与剪枝。

当前已接入时间查询、GeoTIFF、processor_complete、去逻辑分块、去本地索引、去动态调度这六个范围查询入口；各变体自己的局部状态和执行策略保留。保留代码中的原始样本、点/最近邻入口、Spark路径，以及冻结的服务器实验材料是各自既有版本；本次方法修订不将其历史运行数字改记为这份实现的测量结果。正式新性能比较须记录当前模块的版本/哈希、完整环境和统一计时协议。

直接构造最坏需要O(kN²)工作，元数据边界空间为O(kN)，不含物理位置列表。一次查询最多访问N个节点，最坏为O(kN+m)，m为返回块数。
